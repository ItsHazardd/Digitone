DIGITONE {VERSION}

Digitone is a free, portable music player for Windows 10 and 11 (64-bit).
Nothing needs to be installed, and Digitone only reads and writes inside this folder.

START
  1. Extract the whole Digitone folder from the ZIP first.
  2. Double-click Digitone.exe.

WHAT IS IN THIS FOLDER
  Digitone.exe          Starts Digitone.
  Repair Digitone.cmd   Reinstalls Digitone's program files if something breaks.
                        Your music and settings are kept. Works even if Digitone will not open.
  app\                  Digitone's program files and download tools.
  userdata\             YOUR stuff: music (userdata\Music), playlists, settings, lyrics.
                        Created the first time Digitone opens. Back this up.

MOVING DIGITONE
  Copy or move the whole folder anywhere: another PC, a USB drive, another folder.
  Everything comes with it. YouTube sign-ins do not carry over to a different PC;
  just sign in again there.

UPDATING FROM VERSION 5.3.5 OR OLDER
  Use the update button inside Digitone, or copy everything inside this ZIP's
  Digitone folder into your old Digitone folder and open Digitone.exe.
  Your old Data and DigiMusic folders move into userdata automatically.

The YouTube viewer and cover search use Microsoft Edge WebView2, which is built
into Windows 11 and almost every Windows 10 PC.
